Jungle Drum and Breakbeat Machine!
------------------------------------
Creative Vision:

This is my Jungle Drum Machine. It cuts drum breaks up into smaller clips and lets you sequence them in order to make Breakbeats with ease.
------------------------------------
Use in Creative Practice:

This is a useful tool for creating quick mock-up drum loops which might be used in larger projects. It also lets you experiment with different time signatures, giving you loads of control over your rhythms.
------------------------------------
Usage Instructions:

If initialising release version:

Unzip Release.zip.

On Windows, run launch_win.bat or launch_hidden_win.vbs and wait for server to initialise.

Mac is work-in-progress.


If initialising work-in-progress version in the Supercollider IDE:

1. Evaluate the first line to load the buffer.
2. Evaluate BLOCK 1 to slice the buffer into clips.
3. Evaluate BLOCK 2 to initialise the GUI

Once the drum machine is open:

You can play each slice by clicking on the buttons titled "Clip i". 
Bass waves can be played by clicking one of the lettered piano keys.
Sequence drum clips and bass notes by clicking "Record", then selecting the drum and note that will play on each beat.
Change the volume with the "Vol" slider, the playback rate with the "BPM" number box, and the bar count and beats-per-bar with their respective number boxes.
